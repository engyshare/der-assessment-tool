## 0. 핵심 요약 (TL;DR)

1. **편익은 언제나 증분** — 절대값은 편익이 아니며, 기준선은 "아무것도 하지 않음"이 아니라 현실적 대안
2. **중복은 같은 화폐 흐름을 두 번 세는 것** — 동시 발생하는 다중 효과는 중복이 아님. 중복 유형은 네 가지
3. **관점을 섞지 않음** — 사업자·주민·사회의 편익 목록은 다르며, 관점 혼합이 가장 흔한 중복 오류
4. **지원 수준은 결론이지 전제가 아님** — 무지원 경제성을 먼저 산출
5. **입력값은 값만으로 성립하지 않음** — 부기 항목과 신뢰도를 함께 보유하고 결과에 영향도를 표시

## 1. 기준선 — 편익은 언제나 증분

**원칙 1-1.** 모든 편익은 **"설비를 설치하지 않았을 경우"(반사실, counterfactual)** 대비 증분으로만 계상함. 절대값은 편익이 아님

- ❌ "PV 설치 후 연간 전기요금 120만원" — 이는 편익이 아니라 잔여 비용임
- ✅ "미설치 시 300만원 − 설치 후 120만원 = 180만원 절감"

**원칙 1-2.** 기준선 자체도 명시적으로 계산해 리포트에 표시함. 기준선이 보이지 않으면 증분의 타당성을 검증할 수 없음

**원칙 1-3.** 기준선은 "아무것도 하지 않음"이 아니라 **"현실적 대안"** 이어야 함

- 히트펌프의 기준선은 "난방 안 함"이 아니라 "기존 보일러 유지" 또는 "노후 보일러 교체"
- 노후 설비 교체 시점이 도래한 경우 **교체 비용은 기준선에도 발생**하므로, 신규 설비 비용 전액을 증분으로 잡으면 과대계상

## 2. 편익 중복 계상 — 무엇이 중복이고 무엇이 아닌가

"여러 효과가 동시에 발생하는 것"은 중복이 아님. 중복은 **같은 화폐 흐름을 두 번 세는 것**

### 중복이 아닌 것 — 동시 발생하는 다중 효과

에너지를 절감하면 다음이 **동시에** 발생

- 자가소비 시 전력량요금 절감, 피크 감소로 인한 기본요금 절감, 배전선로 증설 지연, 발전소 건설 회피 등

중복이 아닌 사유

- **지불 주체 상이** — 요금 절감은 주민 지갑, 배전망 회피는 한전·사회 지갑, 온실가스는 사회 지갑에서 나옴
- **물리량 상이** — 전력량요금은 kWh에, 기본요금은 kW에 부과됨. 서로 다른 물리량에 대한 서로 다른 요금

### 중복인 것 — 네 가지 유형

#### 유형 A. 동일 물리량의 이중 판매

같은 1 kWh를 두 곳에 쓸 수 없음

| 배타 조합 | 이유 |
| --- | --- |
| 자가소비 절감 ↔ 잉여전력 판매 | 자가소비한 kWh는 잉여가 아님 |
| 잉여판매(직접거래) ↔ 상계거래 | 같은 잉여량을 두 제도로 동시 정산 불가 |
| ESS 방전(피크저감) ↔ ESS 방전(DR 감축) | 같은 시각 같은 kWh는 한 용도뿐 |
| V2G 방전 ↔ 차량 주행 | 같은 배터리 에너지 |

**판별법** — 시간스텝별 에너지 수지식에서 동일 항이 두 편익의 산식에 들어가면 중복임. 검증은 원칙 5-1의 에너지 수지 균형 검증으로 수행함

#### 유형 B. 인과 연쇄의 하류 편익이 상류에 이미 포함된 경우

배전망 건설·유지 비용은 **이미 전기요금의 망이용요금 항목으로 회수되고 있음.** 따라서 전기요금 절감액 안에는 망 관련 비용의 회피분이 **이미 일부 들어 있음**

이 상태에서 "배전망 투자 회피 편익"을 별도로 전액 계상하면 **망 비용을 두 번 세게 됨**

**원칙 2-1 (증분만 계상).** 요금을 통해 이미 회수되고 있는 비용은 요금 절감으로 계상함

망 회피 편익으로 추가 계상할 수 있는 것은 **현행 요금에 아직 반영되지 않은 미래 증설 회피분**뿐임. 이 분리가 불가능하면 **계상하지 않음**

같은 논리가 다음에도 적용됨

| 하류 편익 | 상류에 이미 포함된 부분 | 추가 계상 가능한 부분 |
| --- | --- | --- |
| 배전망 투자 회피 | 현행 망이용요금 | 미래 증설 회피 증분만 |
| 송전손실 감소 | 현행 요금의 손실 반영분 | 한계손실률 기준 증분만 |
| 계통서비스(주파수조정 등) | — | 실제 시장 정산금이 있으면 그것만 |
| 발전 연료비 회피 | SMP 또는 요금 전력량요금 | 없음 (이미 전액 반영) |

#### 유형 C. 동일 효과의 이중 화폐화

온실가스 1 tCO2 저감에 대해 다음 둘을 **동시에** 계상하면 중복임

- 배출권 매각 수익 (KAU 단가 × tCO2) — 사업자가 실제 받는 돈
- 사회적 탄소비용 회피 (사회적 탄소가격 × tCO2) — 사회가 안 치르는 비용

같은 물리적 저감량을 두 개의 가격으로 두 번 화폐화한 것임

**원칙 2-2 (하나의 물리량, 하나의 가격).** 동일 물리량에는 **관점별로 하나의 화폐화 방법만** 적용함

- 사업자 관점 → 배출권 수익 (실제 수취 시)
- 사회 관점 → 사회적 탄소비용 (배출권 수익은 이 관점에서 이전지출)

#### 유형 D. 제도적 배타

물리적으로도 가능하고 지갑도 다르지만 **규정이 금지하는** 경우가 있음

- 상계거래 참여 설비의 REC 발급 제한
- DR 정산금과 특정 요금 인센티브의 중복 수취 금지
- 보조금 중복 지원 금지 (동일 설비에 국비 2개 사업 동시 적용 불가)

물리·회계 논리로는 잡히지 않으므로 **제도 조사 결과를 별도 규칙 테이블로 관리**해야 하며, 제도 개정 시 데이터만 교체할 수 있어야 함

### 관점 분리 — 중복 방지의 근본 장치

**원칙 2-3.** 편익 목록은 관점마다 다름. **관점을 섞는 것 자체가 가장 흔한 중복 오류임**

| 편익·비용 항목 | 사업자 | 참여 주민 | 정부/사회 |
| --- | --- | --- | --- |
| 자가소비 요금 절감 | 계약구조에 따름 | ○ | 이전지출(제외) |
| 잉여판매·직접거래 수익 | ○ | 계약구조에 따름 | 이전지출(제외) |
| REC 수익 | ○ | — | 이전지출(제외) |
| 보조금 수령 | ○ (편익) | ○ (자부담 감소) | ○ (**비용**) |
| 융자 원리금 | ○ (비용) | ○ (비용) | 이자보전분만 비용 |
| 배전망 투자 회피 | — | — | ○ (증분만, 원칙 2-1) |
| 온실가스 저감 | 배출권 수취 시만 | — | ○ (사회적 탄소비용) |
| 회복력(정전 회피) | — | ○ (VoLL) | ○ |

**핵심 규칙 세 가지**

1. **보조금은 사회 관점에서 편익이 아님.** 정부에서 사업자로 이동하는 이전지출(transfer)임. 사회 관점 NPV에 보조금을 편익으로 넣으면 "돈을 옮기기만 해도 사회가 부유해진다"는 결론이 나옴
2. **사업자 관점 NPV에 사회적 편익을 넣지 않음.** 사업자가 받지 않는 돈은 사업자의 수익이 아님. 섞으면 "사업성 있음"이라는 잘못된 결론이 나오고, 정작 필요한 지원 규모를 과소 추정하게 됨
3. **제도화되지 않은 편익은 기본값 0으로 두고 별도 절에 분리함.** 분산편익 크레딧처럼 국내 화폐화 방법론이 없는 항목을 본편익에 섞으면 결과 전체의 신뢰도를 잃음

### 부록 A. 편익 항목 추가 시 실무 적용 절차

편익 항목을 추가할 때 다음 4문항을 순서대로 통과해야 함

```
Q1. 이 편익의 돈은 누구 지갑에서 나오는가?
    → 특정 불가하면 계상 불가

Q2. 그 지갑에서 나오는 돈이 다른 편익 항목에도 이미 들어 있는가?
    → 들어 있으면 증분만 계상 (원칙 2-1)

Q3. 이 편익이 소비하는 물리량(kWh/kW/tCO2)을 다른 편익도 소비하는가?
    → 소비하면 배타 규칙 등록 (유형 A)

Q4. 제도가 동시 수취를 허용하는가?
    → 불허하면 배타 규칙 등록 (유형 D)
    → 제도를 확인하지 못했으면 해당 진술을 `미확인`(근거 표기 기준 축 1)으로
       표기한 뒤 보수적으로 배타 처리
```

## 3. 지원 수준은 결론이지 전제가 아님

**원칙 3-1.** 분석은 **무지원 기준(지원 0)** 경제성을 먼저 산출함. 이것이 모든 판단의 출발점임

**원칙 3-2.** 필요한 지원 수준은 다음 순서로 도출함

```
설비단가·성능·수명·요금·편익단가·할인율 (전제)
        ↓
무지원 경제성 (NPV / IRR / 회수기간)
        ↓
목표 지표와의 격차
        ↓
격차를 메우는 최소 지원 조합 ← 이것이 결론
```

보조율을 먼저 정하고 결과를 확인하는 것은 **사후 평가**이며 별도 모드로만 수행함

**원칙 3-3.** 지원 방식은 재정 부담 현가 기준으로 비교함. "보조 50%"와 "보조 30% + 저리융자 70%"가 사업자에게 동등한 결과를 준다면 **정부 재정 부담 현가가 작은 쪽**이 우월함

**원칙 3-4.** 목표 지표(예: 회수기간 10년)는 **정책 판단 사항**이며 분석의 입력임. 도구가 정할 수 없음

## 4. 시간 처리

**원칙 4-1 (명목/실질 일관성).** 명목 현금흐름은 명목 할인율로, 실질 현금흐름은 실질 할인율로 할인함. 섞으면 20년 분석에서 수십 % 오차가 발생함. 분석 단위를 시나리오 수준에서 1회 선언하고 전 항목에 강제함

**원칙 4-2 (항목별 상승률 분리).** 물가상승률 하나로 모든 항목을 조정하지 않음. 최소한 다음은 분리함

| 항목 | 상승률 |
|---|---|
| 전기요금 | **전기요금 인상률** (일반 물가와 다르게 움직임. 경제성 최대 민감 변수) |
| 연료비(가스 등) | 연료 가격 상승률 |
| O&M·인건비 | 일반 물가상승률 |
| 설비 교체비 | 기술 학습곡선 반영 시 하락 가능 |
| SMP·REC | 별도 전망 또는 케이스 변수 |

**원칙 4-3 (수명주기 전체).** 분석기간은 최장 자원 수명에 맞추되 다음을 반드시 포함함

- 부속설비의 독립 수명 (PV 인버터 10~12년, ESS PCS 등)
- 수명 도달 자원의 교체비 또는 폐기 처리
- 분석기간 종료 시 잔존 수명 비례 **잔존가치**

세 가지 중 하나라도 빠지면 회수기간이 왜곡됨. 특히 잔존가치 누락은 짧은 분석기간에서 경제성을 크게 과소평가함

**원칙 4-4 (성능 저하).** PV 열화(연 0.5~0.7%), ESS 열화(사이클·달력 중 보수적 값)를 반영함. 초년도 성능을 20년간 유지한다고 가정하면 총 발전량이 5~7% 과대해짐

## 5. 물리 정합성

**원칙 5-1.** 모든 시간스텝에서 에너지 수지가 균형해야 함. **오차 1e-6 kWh 미만**을 기준으로 검증하며, 이것이 성립하지 않는 분석 결과는 무효임

```
발전 + 방전 + 계통구매 = 부하 + 충전 + 계통판매 + 손실
```

**원칙 5-2.** 효율·손실을 빠짐없이 반영함. ESS 왕복효율(RTE), 인버터 효율, V2G 충방전 효율, 배터리 열화 보상. RTE 90%를 100%로 가정하면 ESS 편익이 10% 이상 과다해짐

**원칙 5-3.** 열과 전기를 함께 다루는 모델(히트펌프)은 **매체별로 수지를 분리 집계**함. COP를 통해 연결되지만 별개 수지식임

**원칙 5-4.** 계통 연계 용량, ESS SOC 상하한, V2G 최소 보장 SOC 같은 물리 제약을 위반한 운전 결과는 채택할 수 없음. 여러 편익이 동일 자원에 제약을 걸 때는 제약을 합성하고 **실행 전에 충돌을 검사**함

## 6. 가정의 취급

**원칙 6-1.** 모든 입력값은 [[근거 표기 기준]] 5절의 부기 항목을 함께 보유함(값·단위 / 기준연도·버전 / 적용 범위·조건 / 산출 방법·표본 / 출처 / 최종확인일 / 신뢰도). 값만 있는 입력은 검증 불가함

**원칙 6-2.** 신뢰도는 `확정` · `추정` · `가정` 3단계로 구분하고 결과에 함께 표시함. 정의는 [[근거 표기 기준]] 2절을 따르며 여기서 재정의하지 않음

- ⚠️ 종전에 근거 없는 값을 `미확인`으로 적던 표기는 **`가정`으로 바꿔 씀.** `미확인`은 진술의 출처 도달 실패를 뜻하는 별개 축의 표기이며, 같은 토큰을 두 뜻으로 쓰면 판정이 불가능해짐

**원칙 6-3 (중요).** `가정` 값이 있다고 분석을 중단하지 않음. **다만 그 값이 결과에 미친 영향도를 반드시 함께 보고함.** 영향도가 낮은 가정 값은 문제가 아니고, 영향도가 높은 가정 값은 그 결과 전체를 잠정적인 것으로 취급함

**원칙 6-4 (기준연도 조정).** 단가는 기준연도를 보유하고 분석연도로 물가 조정한 뒤 사용함. 2023년 견적을 2026년 분석에 그대로 쓰지 않음

## 7. 결과 보고

**원칙 7-1 (영향도 우선).** 결과 리포트는 **그 결과에 실제로 영향을 미친 인자를 영향도 순으로** 먼저 제시함. 입력 목록을 알파벳순·입력순으로 나열하는 것은 보고가 아님

영향도는 감(感)이 아니라 **민감도 분석 결과로 측정**함. 각 인자를 합리적 범위에서 변동시켰을 때 주 지표가 얼마나 움직이는지로 순위를 매김

**원칙 7-2 (인과 제시).** 각 주요 인자에 대해 다음을 함께 제시함

- 사용한 값과 그 출처·신뢰도
- 그 값이 결과를 어느 방향으로 얼마나 움직였는지
- 합리적 변동 범위에서 결론이 뒤집히는지 여부

**원칙 7-3 (영역 제시).** 단일 케이스 답변("회수기간 12.3년")은 정책 판단에 부족함. **"어떤 조건에서 이 사업이 성립하는가"** 라는 영역(feasible region) 형태의 답이 필요함

**원칙 7-4 (결합 변수).** 변수 조합을 탐색할 때 물리적·경제적으로 함께 움직이는 변수는 묶어서 검토함. "설비단가 최저 + 시공비 최고" 같은 현실에 없는 조합을 만들면 결과 대부분이 해석 불가능한 잡음이 됨

**원칙 7-5 (지표 선택).**

| 지표 | 적합한 용도 | 주의 |
|---|---|---|
| 할인 회수기간 | **주 지표** — 정책·주민 설득 | 회수 이후 편익을 무시함 |
| NPV | 절대 가치 비교 | 규모가 다른 사업 간 비교 부적합 |
| IRR | 규모 무관 수익성 | 현금흐름 부호가 여러 번 바뀌면 복수해. MIRR 병용 |
| B/C | 공공사업 관례 | 무엇을 비용/편익으로 분류하느냐에 민감 |
| LCOE | 발전 자원 간 비교 | **히트펌프·ESS가 섞인 모델 전체 LCOE는 분모 정의가 모호하므로 자원별로만 산출**하거나 분모를 명시 |
| 가구당 월 절감액 | 주민 설득 | 평균값이 개별 가구를 대표하지 않을 수 있음 |

## 8. 원칙 위반 시 결과

| 위반 | 전형적 결과 |
|---|---|
| 기준선 없이 절대값 계상 | 편익 대폭 과대 |
| 관점 혼합 (사업자 NPV에 사회편익) | "사업성 있음" 오판 → 필요 지원 과소 산정 |
| 망 회피 편익 전액 계상 | 이중계상 → 정책 근거 신뢰 상실 |
| 동시 효과를 겁내 하나만 계상 | 과소계상 → 지원 과다 요구 |
| 보조금을 사회 편익으로 계상 | 이전지출을 부가가치로 오인 |
| 잔존가치 누락 | 회수기간 과대 |
| 열화·RTE 미반영 | 편익 5~15% 과대 |
| 명목/실질 혼용 | 20년 NPV에 수십 % 오차 |
| `가정` 값의 영향도 미표기 | 결과 신뢰도를 판단할 수 없음 |
