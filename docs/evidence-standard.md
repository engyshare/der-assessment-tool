## 0. 핵심 요약 (TL;DR)

1. **네 개의 축은 서로 다른 것을 잼** — 확인 상태(진술) / 신뢰도(입력값) / 품질 등급(출처) / 분석 층위(문장). 한 어휘로 뭉치지 않음
2. **`미확인`은 축 1 전용** — 입력값에 근거가 없는 상태는 `미확인`이 아니라 `가정`
3. **공란 금지** — 모든 축은 값을 반드시 적음. 공란은 '해당 없음'과 '미기입'을 구분하지 못함
4. **수치 부기 항목은 하나의 목록으로 고정** — 노트 유형별로 늘리거나 줄이지 않음
5. **이 기준을 다른 노트에서 재정의하지 않음** — 링크로 위임. 정정할 곳이 이 노트 한 곳으로 확정됨

## 1. 축 1 — 출처 확인 상태 (진술 단위)

조사 노트의 **진술 하나하나**에 부여. 그 진술의 원문에 실제로 도달했는지를 표시

| 표기 | 의미 | 부여 조건 |
| --- | --- | --- |
| `확인` | 1차 출처 원문을 열어 해당 진술을 직접 확인 | 등급 A 또는 B 원문에 도달 |
| `간접` | 2차 자료에서만 확인, 1차 출처 미도달 | 등급 C까지만 도달 |
| `미확인` | 출처를 찾지 못했거나 접속 불가 | 도달 실패, 또는 등급 D 자료만 존재 |
| `철회` | 오류로 판명되어 근거에서 배제된 진술 | 정정 시. 행은 지우지 않고 사유를 함께 남김 |

- **공란을 쓰지 않음.** 공란은 '확인됨'과 '확인 안 함'을 구분하지 못함
- `철회`는 진술을 삭제하는 대신 쓰는 표기 — 조용한 삭제는 같은 오류의 재유입을 막지 못함
- ⚠️ `간접`·`미확인` 진술을 근거로 분석 노트에서 단정하지 않음
- ⚠️ 등급 D 자료는 인용하지 않음(3절). 기재가 필요하면 `미확인`으로 두고 확인 대상에 올림

**`미확인`도 출처·최종확인일 칸을 비우지 않음**

`미확인`은 "도달하지 못했다"는 기록이지 "적을 것이 없다"는 뜻이 아님. 두 칸을 `—`로 비우면 **찾아보고 실패한 것과 아예 찾지 않은 것이 구분되지 않아** 공란 금지 원칙이 무력화됨

| 칸 | `미확인` 행에 적는 것 |
| --- | --- |
| 출처 | **탐색 경로** — 찾아본 자료원, 사용한 검색어, 접속 실패한 URL |
| 최종확인일 | **확인 시도일** |

- 무엇을 어디까지 찾았는지가 남아야 다음 사람이 같은 탐색을 반복하지 않음

## 2. 축 2 — 입력값 신뢰도 (계산 입력 단위)

경제성 분석 등에서 **계산에 들어가는 값**에 부여. 값의 출처가 얼마나 단단한지를 표시

| 표기 | 의미 |
| --- | --- |
| `확정` | 공시·고시·계약서 등 공식 출처 |
| `추정` | 업계 견적·유사사례·문헌 |
| `가정` | 근거 없이 분석을 위해 전제한 값 |

- ⚠️ **종전에 `미확인`으로 표기하던 값은 `가정`으로 표기.** `미확인`은 축 1 전용 표기이며, 같은 토큰을 두 축에 쓰면 어느 뜻인지 판정 불가
- `가정` 값이 있다고 분석을 중단하지 않음. 다만 그 값이 결과에 미친 영향도를 반드시 함께 보고

---

## 3. 축 3 — 출처 품질 등급 (자료 단위)

자료 자체의 성격에 부여. 축 1의 부여 조건이 이 등급을 참조함

| 등급 | 출처 유형 | 인용 가능성 |
| --- | --- | --- |
| **A (1차 공식)** | 법령 정보원, 규제기관 결정문, 판결문, 공식 연구기관(IEA·IRENA) 보고서 | 단독 인용 가능 |
| **B (1차 반관급)** | 공식 프로젝트 보고서, 규제기관 해설 페이지 | 인용 가능 (법조항은 A등급 교차 확인 권장) |
| **C (2차 전문 해설)** | 법률해설사, 전문 분석기관 | 참고용, A/B등급 교차 확인 필요 |
| **D (2차 일반)** | 블로그, 일반 뉴스, 위키 | **인용 금지** (탐색용만) |

- 이 하한선은 해외 제도 조사뿐 아니라 **모든 조사 노트에 적용**됨

## 4. 축 4 — 분석 층위 (분석 노트 문장 단위)

| 층위 | 의미 | 취급 |
| --- | --- | --- |
| **사실** | 축 1에서 `확인` 상태로 확보된 진술 | 근거로 사용 가능 |
| **추론** | 사실에서 도출한 판단 | 도출 과정을 함께 적음 |
| **가정** | 확인되지 않았으나 분석을 위해 전제한 것 | **반드시 명시**하고 결론의 민감도를 적음 |

- **축 1과의 관계** — `확인` 상태의 진술만 `사실`로 사용 가능. `간접`·`미확인`에서 끌어온 문장은 `추론` 또는 `가정`
- **폐지된 어휘** — "확립된 사실 / 보유 자료에서 도출한 판단 / 출처 미확인 추론"은 각각 `사실` / `추론` / `가정`에 대응. 별도 어휘로 쓰지 않음
- ⚠️ 세 층위를 같은 문체로 나열하면 읽는 사람이 전부 사실로 받아들임

## 5. 수치·입력값 필수 부기 항목 (정본)

값만 적힌 진술은 검증할 수 없음. 아래 목록을 **노트 유형별로 늘리거나 줄이지 않음**

| # | 항목 | 포함하는 것 | 조사 노트 진술 | 경제성 입력값 |
| --- | --- | --- | --- | --- |
| 1 | 값·단위 | — | 필수 | 필수 |
| 2 | 기준일·기준연도·버전 | 언제 시점의 값인지 | 필수 | 필수 |
| 3 | 적용 범위·조건 | 대상·구간·통계 집계 범위 | 필수 | 필수 |
| 4 | 산출 방법·표본 | 추정치/실측치 구분, 표본 규모 | 필수 | 필수 |
| 5 | 출처 | 문서명 · 위치(조항·페이지·표 번호) · 전체 URL | 필수 | 필수 |
| 6 | 최종확인일 | 실제로 열어본 날짜. `미확인`은 도달 실패를 확인한 시도일 | 필수 | 필수 |
| 7 | 확인 상태 (축 1) | — | 필수 | — |
| 8 | 신뢰도 (축 2) | — | — | 필수 |

> **예시** — "단가 0.05달러"는 검증 불가. "2025-04 고시 기준, 주거용 한정, kWh당 0.05달러(사업자 A 공표값, 실측 집계)"는 검증 가능

- URL은 **전체 주소**로 적음. 단축 링크·검색 결과 링크 금지
- `미확인` 진술은 항목 5·6을 **도달 실패 기록으로 채움** — 항목 5에 탐색 경로, 항목 6에 확인 시도일(1절). `—`나 공란을 쓰지 않음
- ❌ "보도에 따르면", "일반적으로 알려진 바로는", 출처 없는 수치
- ❌ 검색 스니펫만 보고 단정 (원문 미확인 상태)

## 6. 축이 아닌 것 — 혼동 주의

| 표기 | 성격 | 정의 위치 |
| --- | --- | --- |
| ✅ 확인 / ❌ 정정 필요 / ⚠️ 확인 불가 | **검증자가 작성물에 내리는 판정**이며 진술의 확인 상태가 아님 | [[해외사례 조사 원칙]] 원칙 4-2 |
| `SUSTAIN_검증자` / `SUSTAIN_작성자` / `PARTIAL` | 검증자–작성자 간 최종 채택 판정. `REJECT`는 `SUSTAIN_검증자`의 별칭이며 값이 아님 | [[해외사례 조사 원칙]] 원칙 4-2 |

- ⚠️ 검증 판정 `✅`가 붙었다고 축 1이 자동으로 `확인`이 되지 않음. 검증자가 원문에 도달한 경우에만 축 1을 승격
