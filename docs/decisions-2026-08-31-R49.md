## §0 왜 이 판정이 필요했나 — R48 이 결론축을 두 배로 움직였다

무보조 `npv` **−6,289,675 → −12,956,180원** · 결손/총사업비 **64.2% → 132.2%**.
그 이동이 보고서 안에서 **말이 안 맞게 된 자리 셋**을 만들었고, 셋 다 *「무엇이 옳은가」*
가 아니라 **「무엇을 보여 줄 것인가」** 라서 사람 판정이 필요했다.

⚠ **셋 다 결론 수치를 바꾸지 않는다** — 바뀌는 것은 **리포트가 말하는 방식**과
**검사가 재는 대상**이다.

## §1 ★A — 붙임 7 의 **둘째 운전 표를 지운다**

| | |
|---|---|
| **왜 판정이 필요했나** | 붙임 7 은 표를 둘 실었다 — 「파이프라인이 실제로 돈 운전」과 「부하·일사 형상을 **가정한** 운전」. 둘째 표는 *「본 실행에는 없는 가구 부하를 넣어 보면 어떻게 되는가」* 를 보이는 자리였다. **R48 이 본 실행에 부하를 세우면서 두 표가 완전히 같아졌다**(송전·수전 실측 동일값) |
| **무엇이 거짓이 됐나** | 리포트가 *「위 표와의 차이 — **가구 부하 하나**다」* 라고 인쇄한다. **두 표가 같으므로 그 문장은 거짓이다** |
| **정한 것** | **둘째 표(「부하·일사 형상을 가정한 운전」)를 지운다.** 붙임 7 은 「파이프라인이 실제로 돈 운전」 **한 표**만 갖는다 |
| **근거** | 사용자 판정(2026-08-31) |

### 함께 고치는 것 — 붙임 8 「자가소비 편익」 행의 **사유**

지금 *「미반영 — **가구 부하 `Q-3` 확보**하면 해소」* 라고 적는데, **부하는 이미 들어와
있다**(가정값 3,600kWh/년). 남은 것은 **서로 다른 둘**이며 한 문장으로 묶여 있다:

1. **무구조 실행에 `SelfConsumption` 편익 스트림이 배선돼 있지 않다** — 자가소비 효과는
   지금 **수량 배분으로만** 반영되고 별도 편익 항목으로 화폐화되지 않는다
2. **`Q-3` 실측이 오면 가정값(3,600kWh/년)을 교체한다** — 값의 출처 문제이지 배선 문제가 아니다

⚠ **둘을 갈라 적는다.** 묶어 두면 `Q-3` 가 와도 자가소비 편익이 안 생기는 이유를 아무도
설명하지 못한다.

### ⚠ 되돌아올 수 있다

`Q-3` 실측 시계열이 오면 *「가정 부하 ↔ 실측 부하」* 비교가 다시 의미를 갖는다.
**그때 둘째 표를 다시 세운다** — 지금 지우는 것은 *「같은 표를 두 번 싣지 않는다」* 이지
*「비교 자체가 불필요하다」* 가 아니다.

## §2 ★B — **「지원만으로는 안 된다」를 적는다.** 132%를 그대로 쓰지 않는다

| | |
|---|---|
| **왜 판정이 필요했나** | 리포트가 *「결론 전환 지원율 — **132.2%**」* 를 인쇄한다. 그런데 **지원은 최대 100%**(사업비 전액)이므로 132%는 **사업비보다 많은 돈을 주라는 뜻**이고 **있을 수 없는 답**이다. 실제로 그 값을 넣어 재실행하면 `DV-1`(자부담 음수)로 **거부된다** — 즉 리포트가 **달성 불가능한 조건을 달성 조건으로 제시**하고 있었다 |
| **정한 것** | 전환 지원율이 **100%를 넘으면 그 숫자를 답으로 제시하지 않는다.** 대신 **「전액(100%) 지원해도 결론이 전환되지 않는다」**는 사실과 **얼마나 모자라는지**를 적는다 |
| **근거** | 사용자 판정(2026-08-31) |

### ⚠ 이 상태를 이미 예고한 문서가 있다

`docs/evidence/판정요구-이중계상-2026-08-29.md` 가 갈래 丙 을 재면서 *「**丙 이상은 결손이
총사업비를 넘어 지원율로 메우는 답이 성립하지 않는다**」* 고 적어 두었다. **그 상태가
실제로 왔다.** 그러므로 이것은 새로 발견한 것이 아니라 **예고된 자리에 도달한 것**이다.

### 무엇을 적는가 — **작성자가 정하되 셋을 반드시 담는다**

1. **전액 지원해도 전환되지 않는다**는 사실
2. **얼마나 모자라는가** — 원 단위. (100% 지원 = 총사업비 전액을 t=0 에 감액한 뒤의 잔여 결손)
3. **그러므로 지원율 외의 수단이 필요하다**는 것 — 무엇이 필요한지는 **§3 이 만드는 절**이 답한다

🚫 **`DV-1`(자부담 음수 거부)을 풀지 마라.** 그것은 *「지원금이 사업비를 넘는 상태」* 를
막는 정당한 규칙이고, R48 이 그 규칙을 **처음으로 실제 상황에서 만난 것**이다.

## §3 ★C — **「답 없음」으로 끝내지 않는다. 적자 요인과 그 크기를 쓴다**

| | |
|---|---|
| **왜 판정이 필요했나** | *「무엇을 바꾸면 이 사업이 남는가」* 를 찾는 검사가 있는데, R48 이후 **답이 0건**이 됐다. 리포트도 *「결론 전환 인자(단독) — 없음」* 이라고만 적는다. 검사 셋이 「답이 있어야 한다」를 전제해 빨간불이다 |
| **정한 것** | ★ **사용자 문면 그대로** — *「단순하게 답이 없음으로 기재하는 것보다 **주요한 적자 요인이 무엇이고, 이것이 얼마나 영향을 미치는지**에 대한 내용이 기술되야 함」* |
| **근거** | 사용자 판정(2026-08-31) |

### 만들 것 **둘** — 사용자가 「둘 다」를 골랐다

#### ⓐ 새 절 — **「적자는 어디서 오는가」**(구조 분해)

결손을 **항목별로 원 단위로 가르고 크기 순으로** 보인다. 최소 이 넷:

```
① 초기투자
② 운영 단계 20년 누적       ← 편익 − 운영비. ⚠ 이 사업은 여기서부터 마이너스다
③ 교체·잔존 순액             ← 18년차 ESS 교체가 최대
④ 편익 20년 누적
────────────────────────────
   합계 = 결손
```

**착수 재료**(R48 종료 시점 리포트에서 읽은 값 — ⚠ **R49 는 다시 세라**):

| | 값 | 자리 |
|---|---|---|
| 초기투자 | 9,800,000원 | 4.1 |
| 1년차 편익 | 342,060원 | 4.1 |
| 1년차 운영비 | 489,388원 | 4.1 |
| **→ 운영 단계 1년차 순액** | **−147,328원** | (뺄셈) |
| 운영비 중 최대 — **계통 전력 구매** | **289,388원** (운영비의 59%) | 붙임 4 |
| 18년차 ESS 교체비 | 7,001,207원 | 붙임 4 |
| 교체·잔존 순액 | 884,263원 지출 | 붙임 4 |

★ **이 사업은 「투자금을 못 갚는」 정도가 아니라 「운영 단계부터 매년 더 까먹는」 구조**
이고, 그 최대 원인은 **R48 이 처음 넣은 가구 전기요금(계통 구매)** 이다. **그 사실이
심의회에 전달되는 것이 이 절의 목적이다.**

⚠⚠ **수를 문장으로 박지 마라 — 실린 항목에서 지어라.** `core/report/unreflected.py` 가
이미 그 규약을 적어 두었다(*「목록을 문장으로 박아 두지 않는다 … 그때그때 재어 만든다」*).
구성이 바뀌면 박아 둔 문장은 **틀린 채로 계속 인쇄된다.**

#### ⓑ 기존 5.1 표를 넓힌다 — **「이 인자를 고치면 적자가 얼마 줄어드나」**

지금 흔들어 보는 축이 **설비단가 몇 개뿐**이라 답이 안 나온다(실측 — 검사용 하한
`태양광 60만원/kW · 배터리 15만원/kWh` 까지 낮춰도 **약 667만원이 여전히 부족**했다).

**축을 넓힌다.** 최소 후보 — **전기 판매단가 · 가구 전기사용량 · 설비 크기(용량)**.
⚠ **어느 축을 넣을지는 R49 가 정하되, ⓐ 의 분해에서 큰 항목부터 고른다** — 크기 순으로
고르지 않으면 「흔들어 봤는데 안 움직인다」가 반복된다.

⚠ 대장 축을 늘리려면 `docs/assumptions.yaml` 의 `sensitivity` 와
`core/casegrid/ledger_levels.py::_LEDGER_VARS` 가 **함께** 움직인다(R48/WP-B 가 부하 축에서
같은 일을 했다).

#### ⓒ 「전환 인자 없음」은 **그대로 둔다 — 다만 왜 없는지를 설명한다**

지금 리포트가 「없음」이라 적는 것 자체는 **정직하고 옳다.** 지울 대상이 아니다.
**바뀌는 것은 그 옆에 ⓐ·ⓑ 가 서서 「없는 이유」와 「그럼 무엇이 필요한가」를 말하는 것**이다.

### 검사 셋은 **전제를 바꾼다**

`test_case_report.py`(2) · `test_combined_scenarios.py`(1) 은 *「전환 인자가 존재한다」* 를
전제한다. **그 전제를 「0건이면 리포트가 0건이라 적고, 적자 분해를 함께 싣는다」로 바꾼다.**
⚠ **검사용 탐침 단가를 더 낮춰 억지로 답을 만들지 마라** — 현실에 없는 설비값이 되고,
*「이 값이면 됩니다」* 가 실현 불가능한 조건이 된다.

## §5 R49 가 함께 받는 것 — R48 이 남긴 **배선 넷**

판정이 필요한 것은 아니고 **일이 남은 것**이다. `status.md` 「다음에 집을 것」 ★D~★H:

- **`NWAs`·`CP` 를 내는 자원이 없다** — `ESSOperatingMode` 에 「계통 방전」·「준중앙급전
  등록」 두 종 신설(§16.5 조항 동반)
- **정책 경고의 임자 판정** — §6 은 **편익** 단위로 갈랐는데 `policy_warnings()` 는
  **자원**의 훅이다
- **`Payer` 열거가 「배전사업자」와 「전력시장」을 구분하지 않는다**(§16.2 대상)
- **`TOU_ARBITRAGE` 가 편익을 하나도 내지 않는다** — 오매핑을 뗀 자리가 비어 있다
