## 8단계 — 지표

**ⓐ 전제한 수치**

7단계 현금흐름 행 전체 + 2단계 초기투자 9,800,000원 + 1단계 할인율 4.5% · 분석기간 20년.

**ⓑ 계산된 수치**

| 지표 | 값 |
|---|---|
| 할인 회수기간(`payback_years`) | 분석기간 내 미회수 |
| 순현재가치(`npv`) | -11,537,129원 |
| 초기지출(지원 반영 후) | 9,800,000원 |

**ⓒ 다음 단계로 넘긴 값**

이 지표(할인 회수기간·순현재가치)가 9단계 변형별 비교와 심의용 리포트 5.1 영향도 분석의 기준값이다.

**ⓓ 계산 수식**

**연 순현금흐름**
- 연 순현금흐름 = 연 편익 - 연 운영비
- `CF = B - C`
- -38,237원 = 282,930원 - 321,167원

**순현재가치**
- 순현재가치 = 분석기간 동안의 순현금흐름을 할인해 더한 뒤 초기투자를 뺀 값
- `NPV = Σ(t=1..T) CF_t / (1+r)^t - I₀`
- -11,537,129원 = Σ(t=1..20) CF_t / (1+0.045)^t - 9,800,000원

**할인 회수기간**
- 할인 회수기간 = 누적 할인 현금흐름이 초기투자에 도달하는 시점. 분석기간 안에 도달하지 못하면 「미회수」
- `min{ T' : Σ(t=1..T') CF_t / (1+r)^t ≥ I₀ }`
- 분석기간 내 미회수 — I₀ = 9,800,000원 · r = 4.5% · T = 20년

**결론 전환 지원율**
- 결론 전환 지원율 = 현 지원율 - 순현재가치 ÷ 총사업비. 지원은 t=0 초기지출 감액이고 순현재가치 산식은 초기투자를 할인하지 않으므로, 지원 1원이 결론 축을 정확히 1원 올린다
- `s* = s - NPV / I_total`
- 117.7% = 0.0% - (-11,537,129원) ÷ 9,800,000원 — ⚠ 지원 상한 100%(사업비 전액)를 넘어 지원율로는 답이 성립하지 않는다

**전액 지원 시 잔여 결손**
- 전액 지원 시 잔여 결손 = 순현재가치 + (지원 상한 - 현 지원율) × 총사업비. 지원은 t=0 초기지출 감액이므로 지원율을 상한(100%)까지 올려도 결론 축은 남은 지원분만큼만 오르고, 그 위로는 올릴 곳이 없다
- `R = NPV + (1 - s) × I_total`
- -1,737,129원 = -11,537,129원 + (100.0% - 0.0%) × 9,800,000원
