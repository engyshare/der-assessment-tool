- **`quick_preset_grid()`** — 결합 집합이 PV·ESS·시공비 **셋뿐**이고 히트펌프가
  빠져 있었다. 케이스 수는 `3 × 3 × 3 = 27` 로 **문면과 같아서 개수 검사로는
  절대 드러나지 않는다.** → **R26 이 고쳤다** (아래 §5).

  없고** 뒤 3변수(PPA 단가·PV 이용률·EV 보급률)가 통째로 빠진 채 설비단가 4종을
  독립축으로 펼쳐 729를 맞췄다. spec 의 v0.5 정정 사유가 구성을 못 박는다 —
  *「결합 2집합 + 독립 4변수 × 각 3수준 = 3 × 3 × 3⁴ = 729」*.
  **미해결** — 새 변수 셋의 `target` 을 무엇으로 둘지가 정해져야 한다
  (`CaseVariable.target` 기본값은 `"scalar"` 이고, 이 값이 실제 파라미터 경로로
  쓰이는 배선은 아직 없다). 배선 없이 이름만 넣으면 「729가 맞는」 상태가 한 번
  더 만들어질 뿐이다.

  파일 머리말이 스스로 *「스냅샷이며 정확성의 증거가 아니다」* 라고 적는다.
