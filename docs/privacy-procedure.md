# 개인정보 처리 절차 (SC-3)

본 문서는 실증 참여 가구의 실제 전력 사용량(부하 시계열) 데이터를 시스템에 반입할 때, 익명화되지 않은 원본이 저장소나 DB에 유입되는 것을 원천 차단하기 위한 절차를 규정한다. 반입 후 삭제는 허용되지 않는다.

## 1. 식별 정보 제거 규칙 (반입 전 차단)
원본 데이터 수령 시, 반입 전 **저장소 외부 격리 환경**에서 다음 식별 정보를 완전히 제거한다.
- 이름, 전화번호, 상세 주소(동·호수 등)
- 계량기 고유 번호 및 고객 번호
- 기타 특정 가구를 유추할 수 있는 모든 메타데이터

## 2. 익명 집계 단위
- 개별 가구 데이터는 반입 전 최소 **군집(Cluster) 단위** 또는 **임의의 익명 ID(Household_01 등)** 로 변환되어야 한다.
- 특정 가구가 노출되지 않도록 가구별 시계열을 집계(Aggregation)하여 사용하거나, 주소지 대신 통계적 그룹으로 묶는다.

## 3. 데이터 반입 시점 검증 절차
데이터를 저장소의 `fixtures/` 또는 DB에 커밋/복사하기 **직전에** 다음 절차를 거친다.
1. **수동 검사 (사람의 훑기)**: 담당자가 눈으로 직접 CSV/Excel 파일을 열어 식별 정보가 없는지 확인한다. 기계가 잡지 못하는 맥락적 식별 정보를 차단하기 위한 필수 절차다.
2. **기계 검사**: 저장소의 `scripts/check_disclosure.py` 와 `gitleaks` (pre-commit 훅)를 반드시 통과해야 한다.
3. **승인 및 기록**: 수동 검사와 기계 검사를 모두 마친 담당자는 PR 본문에 "SC-3 개인정보 훑기 및 기계 검사 완료"를 명시해야 한다.
