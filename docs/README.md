# docs/

## 정본 사본 — 편집하지 마십시오

| 파일 | 정본 위치 |
|---|---|
| `domain-rules.md` | 볼트 `0. rules/분산자원 경제성 평가 원칙.md` |
| `evidence-standard.md` | 볼트 `0. rules/근거 표기 기준.md` |

위 두 파일은 볼트에 있는 **정본(定本)의 읽기 전용 거울**입니다. 정본은 이 프로젝트
밖의 노트에서도 참조되므로 저장소로 옮기지 않고, 대신 사본을 둡니다.

**바이트 동일해야 합니다.** 머리말·주석·서식 어느 것도 추가하지 마십시오.
동기화 메타데이터(정본 경로·시각·해시)는 사본이 아니라 `source-rules.lock`에
있습니다. 사본에 한 줄이라도 넣으면 해시가 달라져, 볼트에 접근할 수 없는
환경(CI)에서 대조가 불가능해집니다.

```
python scripts/check_source_rules.py
```

이 검사가 사본 오염을 잡습니다. 다음 세 가지를 구분해서 보고합니다.

| 상황 | 보고 |
|---|---|
| 정본이 개정됨 | 해시 불일치 — 정본이 개정되었습니다 |
| 사본을 직접 고침 | 저장소 사본이 정본과 다름 |
| 볼트 없이 실행 (CI) | 정본 개정 또는 사본 오염 — 볼트 환경에서 재실행하여 구분 |

### 개정하려면

정본에서 고칩니다. 그다음 `spec §16.5.3` 절차를 따릅니다.

1. 영향 FR 전수 재검토 (`§16.5.1` 파생 관계표)
2. 어휘가 바뀌었다면 DB enum·UI 라벨·테스트 픽스처까지 추적
3. `python scripts/check_source_rules.py --update` 후 **검토하고** 커밋
4. 사본 재복사

사본을 고쳐서 정본을 앞지르면 정본이 둘이 됩니다. 그 시점부터 어느 쪽이
맞는지 판정할 방법이 없습니다.
