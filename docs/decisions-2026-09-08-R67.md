## 3. 조사와 채택을 구분한다

공개 견적·조달내역·제조사 자료와 학술 가정값을 구분한다. 장비 가격은 배터리,
PCS, 인버터, 설치·공사, 세금의 포함 범위와 용량·출력·가격 기준연도를 함께 기록한다.
다른 규모의 장비를 그대로 환산하거나 보증기간을 교체주기로 읽지 않는다.
자료가 없으면 없다고 남기고, 채택 가능한 잠정값은 근거·한계·교체 조건을 명시한다.
조사는 공개 자료 열람 범위다. 업체에 문의를 보내거나 구매를 진행하는 지시는 아니다.

본문 재구성과 기본 가구 조건에 대한 사람 판단은 끝났다. 조사 착수도 승인되었다.
이 문서의 작성은 구현·조사·독립 검증 완료를 뜻하지 않는다. 다음 작업과 진행 상태는
`status.md`의 「다음에 집을 것」이 갖는다.

## 4. 검증모드 보고서 개편 요구

추가로 다음을 구현한다.

1. 검증모드의 과다한 내용을 단계별 산출물로 나누고 목차를 제공한다.
2. 가구 수요 설명을 별도 단계로 분리한다. 가구당 일반용 전력, 히트펌프, 전기차의 합계와 각 산출식을 보여준다. `HP+EV` 소계와 `일반+HP+EV` 총계를 혼동하지 않게 표시한다.
3. 2단계는 1가구 적정 용량을 먼저 제시한 뒤 20가구 확대 구성을 설명한다. 진단값과 실제 실행값을 구분한다.
4. 실제 채택 용량을 적용한 경우 계절별 24스텝 일일 부하, 공급, ESS 충방전, 한전 수전·역송 프로파일을 제공한다. 적용 전이면 결과를 만들어 낸 것처럼 표시하지 않는다.

현재 재확인된 기준은 일반 3,600 + 히트펌프 3,289 + 전기차 2,784 = 가구당 9,673 kWh/년, 20가구이며,
기존 실행 구성은 PV 60 kW·ESS 200 kWh·ESS 출력 100 kW이다. 이 수치는 새 조사나 개편 결과가 아니며,
다음 세션에서 대장과 실행 경로를 다시 대조해야 한다.
