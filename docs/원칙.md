# 폴더별 CLAUDE.md 작성 원칙

## 형식

- 마크다운 헤딩(`##`) 사용
- 이모티콘·기호(예: 경고 아이콘) 배제
- 개조식 표현 — 불필요한 어미 삭제

## 구조

- 금지사항과 허용사항(절차) 분리 — "하지 마라 + 대신 이렇게 하라"를 한 항목에 섞지 않음
- 해당 폴더 범위로 한정 — 다른 폴더(코드) 구조 설명은 그 폴더의 CLAUDE.md 담당
- 폴더 내 기존 문서(README.md 등)와 헤딩 이름 일치 — 같은 폴더를 다른 이름으로 부르지 않음

## 분량

- 간결하게, 필요한 만큼만
- 세부 절차는 참조 문서로 위임, 본문에 전문을 옮기지 않음

## 참고 정보 포함 기준

- 다른 폴더의 아키텍처 전체 설명은 배제
- 이 폴더의 파일과 직접 관련된 만큼만 한 줄로 요약
